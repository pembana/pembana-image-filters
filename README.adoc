Java image-processing filters maintained by Pembana™, based on Jerry Huxtable’s JHLabs filters.

I did not see any Mavenized version of Jerry Huxtable's *Java Image Processing Classes*.

This repo contains all classes as available via the download at:

http://www.jhlabs.com/ip/filters/download.html

== Getting Started

Build from source with JDK 21 or later using `./mvnw clean verify`. The library targets Java 17.

=== Migrating from image-filters-4j

For an existing checkout, update the remote:

[source,shell]
----
git remote set-url origin https://github.com/pembana/pembana-image-filters.git
----

The Maven coordinates are now `com.pembana.imaging:pembana-image-filters`.
If you previously used `com.hillert:image-filters-4j`, update your dependency declaration
using the examples below. GitHub's repository redirects do not redirect Maven dependencies.
The Java packages and filter APIs are unchanged by the repository move.

=== Maven

To use the filters in your Maven project, add the following dependency to your `pom.xml`:

[source,xml,subs="verbatim,quotes,attributes"]
----
<dependency>
    <groupId>com.pembana.imaging</groupId>
    <artifactId>pembana-image-filters</artifactId>
    <version>{main-release-version}</version>
</dependency>
----

If you are using Gradle, add the following to your `build.gradle`:

[source,groovy,subs="attributes"]
----
implementation 'com.pembana.imaging:pembana-image-filters:{main-release-version}'
----

==== Using Snapshot Versions

Currently, snapshot releases are available via the following Maven repository:

[source,xml]
----
<repository>
  <id>snapshots-repo</id>
  <url>https://central.sonatype.com/repository/maven-snapshots</url>
  <releases>

=== Usage

[source,java,indent=0]
----
    final ClassLoader classLoader = Thread.currentThread().getContextClassLoader();
    final String imageResourcePath = "images/image-filters-4j.png";
    final BufferedImage originalBufferedImage;

    try (InputStream inputStream = classLoader.getResourceAsStream(imageResourcePath)) {
        if (inputStream == null) {
            throw new IllegalStateException("Resource not found: " + imageResourcePath);
        }
        originalBufferedImage = ImageIO.read(inputStream);
    }
    catch (IOException ex) {
        throw new IllegalStateException("Unable to read image at " + imageResourcePath, ex);
    }

    final BufferedImage grayscaleBufferedImage = new GrayscaleFilter().filter(originalBufferedImage, null);

    final Path outputPath = Path.of("target", "image-filters-4j_output.png");

    try {
        Files.createDirectories(outputPath.getParent());
        ImageIO.write(grayscaleBufferedImage, "png", outputPath.toFile());
    }
    catch (IOException ex) {
        throw new IllegalStateException("Unable to write image to " + outputPath, ex);
    }
----
